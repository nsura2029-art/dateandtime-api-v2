2. Filter Derivation: Calendarific → M14

Each Calendarific holiday has a type field that maps to one of the 36 M14 filter codes:

Calendarific type M14 filter code Examples
National holiday PUBLIC_NATIONAL Independence Day, Republic Day, Canada Day
Local holiday PUBLIC_LOCAL State-specific gazetted (US states, IN states)
Common local holiday PUBLIC_COMMON_LOCAL Family Day (5 provinces), Civic Holiday
Observance OBS_COMMON Valentine's Day, Mother's Day
Local observance OBS_LOCAL Heritage Day, Natal Day
Optional holiday OPTIONAL_HOLIDAY Boxing Day (most provinces)
Half-day holiday HALF_DAY_HOLIDAY Christmas Eve (some countries)
De facto holiday DE_FACTO_HOLIDAY Day after Thanksgiving (US)
Flag day FLAG_DAY Canada Flag Day (Feb 15)
United Nations observance UN_OBSERVANCE International Day of Peace
Worldwide observance WORLD_OBSERVANCE World Poetry Day
Season SEASON Equinoxes, Solstices
Clock change/Daylight Saving Time CLOCK_CHANGE DST start/end
Christian CHRISTIAN_MAJOR Christmas, Easter, Good Friday
Hebrew JEWISH_MAJOR Passover, Yom Kippur, Hanukkah
Muslim MUSLIM_MAJOR Eid al-Fitr, Eid al-Adha, Ramadan
Orthodox ORTHODOX_MAJOR Orthodox Christmas, Orthodox Easter
Hinduism HINDU_MAJOR Diwali, Holi, Navratri
Sporting event SPORTING_EVENT Super Bowl, Cricket World Cup
Bonus: Religious types (Christian, Hinduism, Muslim, Hebrew, Orthodox) get a SECOND filter code:
  • CHRISTIAN_MAJOR = Christmas, Easter, Good Friday, Easter Monday
  • CHRISTIAN_MORE = Ash Wednesday, Pentecost, etc.
  • HINDU_MAJOR = Diwali, Holi, Navratri, Dussehra, Raksha Bandhan, Janmashtami
  • MUSLIM_MAJOR = Eid al-Fitr, Eid al-Adha, Ramadan
  • JEWISH_MAJOR = Passover, Yom Kippur, Rosh Hashanah, Hanukkah
  • ORTHODOX_MAJOR = Orthodox Christmas, Orthodox Easter
This lets the timeanddate-style UI show "Major Christian (5)" + "More Christian (12)" independently.

6. What We Keep & What We Lose

✅ What we KEEP from Calendarific (rich data)

  • All public holidays (national + local + common local)
  • All optional holidays (Boxing Day, etc.)
  • All observances (Valentine's, Mother's Day, etc.)
  • All seasons (equinoxes, solstices) — 4 per country/year
  • All clock changes (DST) — 2 per country/year
  • All religious holidays with MAJOR/MORE split:
    • Christian: Christmas, Easter, Good Friday, etc.
    • Hindu: Diwali, Holi, Navratri, etc.
    • Muslim: Eid al-Fitr, Eid al-Adha, Ramadan
    • Jewish: Passover, Yom Kippur, Hanukkah
    • Orthodox: Orthodox Christmas, Easter
  • Sporting events (Super Bowl, Cricket World Cup)
  • Local observances (Heritage Day, etc.)

❌ What we LOSE (not in Calendarific)

  • Some UN observances that hebcal/un_official had more depth on
  • Some Jewish-specific holidays (Yom HaShoah, etc.) that hebcal tracked but Calendarific missed
  • The "computed_federal_us" derived holidays (3 — these were duplicates of Calendarific anyway)
  • The nager.date entries (these were a strict subset of Calendarific)

Net impact: For most user-facing filters, the count is similar or higher. The losses are mostly in deep UN/religious observances that timeanddate doesn't show prominently anyway.

7. SQL Cleanup Plan (NOT YET APPLIED — preview only)

Status: Preview only. Review the data, then I'll apply after quality gate pass. 
-- Step 1: Remove sources from the source registry
DELETE FROM holiday_source WHERE code IN (
  'nager_date', 'un_official', 'hebcal', 'computed_federal_us'
);

-- Step 2: Remove holiday_occurrence_source links to those sources
DELETE FROM holiday_occurrence_source
WHERE source_key IN (
  'nager_date', 'un_official', 'hebcal', 'computed_federal_us'
);

-- Step 3: Delete orphan occurrences (no sources left)
DELETE FROM holiday_occurrence
WHERE id NOT IN (SELECT occurrence_id FROM holiday_occurrence_source);

-- Step 4: Delete orphan concepts (no occurrences left)
DELETE FROM holiday_concept
WHERE id NOT IN (SELECT concept_id FROM holiday_occurrence);

-- Step 5: Re-derive filter assignments for all remaining occurrences
-- (Run the calendarific_to_m14.py derivation on each occurrence
--  and rewrite holiday_occurrence_filter accordingly)
DELETE FROM holiday_occurrence_filter;

-- Step 6: Re-insert filter assignments from Calendarific derivation
-- (Generated by lib/calendarific_to_m14.py apply_to_holiday_occurrence_filter)
Result after applying this plan:
  • Single source: calendarific_api for all 190 countries
  • All holidays have a M14 filter code derived from Calendarific's type field
  • Religious holidays have 2 filters (primary + MAJOR/MORE tradition)
  • 8 universal presets available for any country via bitmask
  • Per-country filter panel auto-computed
