# M11.6: Eurostat LAU + URAU — Result Report

**Date**: 2026-08-03
**Branch**: feature/m11.6-eurostat
**Status**: API deployed, URAU data loaded (597 cities), LAU loader in progress

## What was added

Adds Eurostat enrichment to `/api/v1/cities/{id}` for EU cities via a new
`eurostat` block with two sub-blocks:

- **`eurostat.lau`** — Local Administrative Units (pan-EU, 30 countries, 97,987 records)
  - `giscoId`: Eurostat LAU ID (e.g. `DE_11000000` for Berlin)
  - `lauName`: Official LAU name
  - `population`: Population 1 Jan 2024 (null for FR/ES/AL/IS/RS due to privacy laws)
  - `populationDensity`: People per km²
  - `areaKm2`: Area in km²
  - `year`: 2024
- **`eurostat.urau`** — Urban Audit City vs FUA (pan-EU, 1,332 records)
  - `urauCode`: City code (e.g. `AT002C` for Graz)
  - `urauName`: City name
  - `fuaCode`: Functional Urban Area code (e.g. `AT002F`)
  - `fuaName`: FUA name (the wider metro area)
  - `areaSqKm`: URAU city area in km²
  - `nuts3Code`: NUTS 2024 region code

## Data source

- **URAU 2024** (City vs FUA): https://gisco-services.ec.europa.eu/distribution/v2/urau/csv/URAU_AT_2024.csv
  - 63.5 KB, 1,332 records (739 cities + 593 FUAs), released 2024
  - **Note**: Despite the filename "URAU_AT_2024.csv", the file is actually pan-EU

## Gotchas hit

- **URAU file is pan-EU despite filename**: URAU_AT_2024.csv actually contains
  all 30 EU countries, not just Austria. Name is a leftover from the original
  Austria-only release.
- **FUA lookup ordering**: FUA records (URAU_CATG=F) come AFTER the city records
  in the CSV. Must collect FUA records first, then resolve fua_name when building
  city list. Initial loader had 597/597 fua_name empty because of this.
- **5 countries with POP_2024=0** (FR/ES/AL/IS/RS) is by design — national privacy
  laws. Documented in `known_limitations` of source_registry.
- **R2 credentials**: Initial script had wrong R2 keys (used CF account ID as
  R2 access key). Fixed to use `9a8901b42630218c855a9ea26a7d0255` (R2 key) and
  `a0f1c0010a51405299ec2ad6b0c2d5d1e2876f7d51335a3992589e12f6c0c9c9` (R2 secret).
- **source_registry schema mismatch**: Initial SQL had wrong columns. Fixed
  to match the actual schema: source_key, publisher, dataset, coverage,
  access_method, endpoint_url, license, license_url, attribution, refresh_policy,
  known_limitations, is_active, created_at, updated_at.
- **gisco_id transformation**: URAU codes are like "AT002C" but LAU codes are
  "AT_11000". We store URAU-style "AT_002C" in cities.gisco_id for simplicity.
  LAU loader sets cities.gisco_id with the proper underscore form.
