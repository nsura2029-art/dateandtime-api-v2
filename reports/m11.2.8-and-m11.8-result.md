## What we have in data

### M11.2.8: Wikidata P-codes (5,000 cities)
- `wikidata_properties` table: P31 (instance of), P17 (country), P131 (admin entity), P625 (coord), P421 (timezone)
- 100% have instance_of, country_qid, and coord
- 99.9% have admin_qid
- 42% have timezone_qid (P421 is sparse on Wikidata)

### M11.8: NCEI GSOM Climate (10,559 cities)
- `climate_real` table: monthly avg_high_c, avg_low_c, precipitation_mm
- Source: NCEI Global Summary of the Month, 2020-2023 (4 years)
- Matched via nearest GHCN-Daily station within 1-degree grid
- Median distance to station: 20 km
- 2,623 cities are >100 km from any station (kept anyway with caveat)
- 5,900 of 10,383 unique stations returned 404 (no GSOM file) — fall back to next-nearest

## Gotchas hit

### M11.2.8
- **D1 100-var limit**: 9-col inserts with BATCH_ROWS=12 = 108 vars (over limit). Use BATCH_ROWS=11 (99 vars).
- **P625 WKT format**: returns "Point(long lat)" — parse with regex
- **`as_completed` typo**: I had `as_comyncio` first (Python 3.13 only)
- **Wikidata SPARQL**: 1,000 Q-ids per POST request max for response size

### M11.8
- **Open-Meteo has a sticky 5/min rate limit** that persists after waiting
  - Tested 10 workers, 5 workers, 2 workers, 1 worker — all hit 429
  - Even after 5 min wait, still 429
  - Switched to NCEI GSOM (different provider, different limits)
- **NCEI GSOM header is QUOTED** (`"TMAX"`, not `TMAX`) — used Python `csv` module
- **50% of GHCN-Daily stations have no GSOM** (404) — fall back to next-nearest
- **1-degree grid is enough** for nearest-station match (median 20 km)
- **`/data/gsom/access/` is per-station CSV**, not bulk — easy to parallelize

## Architecture

### M11.2.8
```
SPARQL query (1,000 Q-ids per POST) → parse P31/P17/P131/P625/P421
  → INSERT OR REPLACE (qid is PK) → wikidata_properties
  → /cities/{id} LEFT JOIN wikidata_staging + wikidata_properties
```

### M11.8
```
ghcnd-stations.txt (132K stations) → 1-degree grid
  → for each top 30K city: find nearest station
  → download NCEI GSOM CSV per station
  → parse TMAX/TMIN/PRCP for 2020-2023
  → INSERT OR REPLACE (city_id, month) → climate_real
  → /cities/{id}/climate: SELECT from climate_real ORDER BY month
  → fallback to lat-based model if no rows
```
